## How to run

From a fresh clone (Python 3.10+):

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python generate_data.py            # prints 24 1224 48
python part_a_clean_eda.py
python part_b_regression.py
python part_c_classification.py
python part_d_segments.py
python package_model.py            # regenerates models/delay_model.pkl
python predict_delay.py            # writes outputs/new_shipment_actions.csv
```

`models/delay_model.pkl` is regenerated by running `python package_model.py`. The committed pickle loads reliably only on the
scikit-learn version pinned in `requirements.txt`; if your installed versions differ, re-run `package_model.py` instead of loading it.
